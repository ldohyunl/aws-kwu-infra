<ELB 생성 (Web server구축/확인)>

1. Classic LoadBalancer
1) CLB 보안그룹 생성
[EC2] - [보안그룹] - [보안그룹 생성] 클릭

 
보안 그룹 이름과 설명은 ‘KWU-PRD-VPC-CLB-SG’로 입력하며
 > VPC는 이전에 생성한 ‘KWU-PRD-VPC’로 지정
 > 인바운드와 아웃바운드 규칙은 생성 이후 지정할 것이므로 [보안 그룹 생성] 클릭
 > 생성 시 다음과 같이 결과가 나옴
   인바운드 규칙 설정을 위해 [인바운드 규칙] - [인바운드 규칙 편집] 클릭
 > [규칙 추가] 클릭 후 아래 표를 참고하여 인바운드 규칙 설정 후 [규칙 저장] 클릭
   HTTP	, 소스 : Anywhere IPv4	0.0.0.0/0

2) CLB 생성
[EC2] - [로드밸런서] 클릭 후 ‘Classic load Balancer’ 선택
 > 로드 밸런서 이름은 ‘ KWU-PRD-VPC-CLB ’로 입력 
 > 체계는 ‘인터넷 경계로 지정
 > VPC는 생성한 ‘JON-PRD_VPC’로 지정 
 > 가용영역은 아래와 같이 설정
	- ap-northeast-2a : KWU-PRD-VPC-NGINX-PUB-2A
	- ap-northeast-2c : KWU-PRD-VPC-NGINX-PUB-2C 
 > 보안그룹은 아래와 같이 ‘KWU-PRD-VPC-CLB-SG’로 지정   
 > 리스너 및 라우팅 에서 리스너 HTTP:80 등 나머지는 디폴트로 두고 [로드밸런서 생성] 클릭 
 
생성된 인스턴스 두고 하단에 [대상인스턴스] 선택 후 [인스턴스 관리] 클릭    
 > 아래 나타난 인스턴스 모두 체크 후 [변경내용 저장] 클릭 
 > 다시 CLB화면 돌아와서 [DNS 이름] 복사하여 빈 화면에 입력하면 아래 사진과 같이 로드밸런서에 2개의 인스턴스가 연결된 것을 확인할 수 있음   


결과 
**새로고침**하면 변경되는 것을 확인할 수 있음

# 1. 변수 선언
# CLB_DNS 변수에 로드밸런서 주소를 넣어주세요.
CLB_DNS="kwu-nginx-clb-366373775.ap-northeast-2.elb.amazonaws.com"

# 2. 한 줄에 한 회차씩 완벽하게 매핑되는 숏 가이드 스크립트
for i in {1..10}; do
    # curl 결과를 변수에 담아 중복을 제거한 후 한 줄로만 뽑아냅니다.
    RESULT=$(curl -s --connect-timeout 2 "http://$CLB_DNS" | grep -o -E "Nginx-2A|Nginx-2C" | head -n 1)
    
    # 템플릿에 맞추어 깔끔하게 출력
    echo "[$i회차 요청 결과] 👉 $RESULT"
    sleep 0.5
done
