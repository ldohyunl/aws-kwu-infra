<EC2 생성 (Tomcat Was server)>
1. 보안그룹 생성
Web 서버에 대한 보안그룹을 생성하였으므로 Was 서버에 대한 보안그룹 생성      
[VPC] - [보안 그룹] - [보안 그룹 생성] 클릭

보안 그룹 이름과 설명은 ‘KWU-PRD-VPC-TOMCAT-PRI-SG-2A’로 입력하며
VPC는 이전에 생성한 ‘KWU-PRD-VPC’로 지정
인바운드와 아웃바운드 규칙은 생성 이후 지정할 것이므로 [보안 그룹 생성] 클릭

생성 시 다음과 같이 결과가 나옴
인바운드 규칙 설정을 위해 [인바운드 규칙] - [인바운드 규칙 편집] 클릭

[규칙 추가] 클릭 후 아래 표를 참고하여 인바운드 규칙 설정 후 [규칙 저장] 클릭
사용자 지정 TCP	8080	Anywhere IPv4	0.0.0.0/0
SSH	22	Anywhere IPv4	0.0.0.0/0
http	80	Anywhere IPv4	0.0.0.0/0
https	443	Anywhere IPv4	0.0.0.0/0

**‘KWU-PRD-VPC-TOMCAT-PRI-SG-2C’ 보안그룹도 위와 같이 동일하게 생성**  

[VPC] - [보안 그룹] - [보안 그룹 생성] 클릭

보안 그룹 이름과 설명은 ‘KWU-PRD-VPC-TOMCAT-PRI-SG-2C’로 입력하며
VPC는 이전에 생성한 ‘KWU-PRD-VPC’로 지정
인바운드와 아웃바운드 규칙은 생성 이후 지정할 것이므로 [보안 그룹 생성] 클릭

생성 시 다음과 같이 결과가 나옴
인바운드 규칙 설정을 위해 [인바운드 규칙] - [인바운드 규칙 편집] 클릭

[규칙 추가] 클릭 후 아래 표를 참고하여 인바운드 규칙 설정 후 [규칙 저장] 클릭
사용자 지정 TCP	8080	Anywhere IPv4	0.0.0.0/0
SSH	22	Anywhere IPv4	0.0.0.0/0
http	80	Anywhere IPv4	0.0.0.0/0
https	443	Anywhere IPv4	0.0.0.0/0



2. Was 전용 서버 생성 (`KWU-PRD-VPC-TOMCAT-PRI-2A`)
* PRI 용도 서브넷 생성 안했으면 서브넷 생성부터 해야함. 
02-2. 이번에는 Private 영역의 서브넷 2개 생성, [서브넷 생성] 버튼 클릭 
    1) AZ : 2A 
     KWU-PRD-VPC-TOMCAT-PRI-2A      (10.250.2.0/24) - 251   
	 > VPC ID는 생성한 ‘KWU-PRD-VPC’로 연결
	 > 서브넷 이름은 ‘KWU-PRD-VPC-TOMCAT-PRI-2A’로 입력
	   가용영역은 ‘아시아 태평양(서울) / ap-northeast-2a’로 지정
	   IPv4 서브넷 CIDR 블록은 ‘10.250.2.0/24’로 입력 후 [서브넷 생성] 클릭
	2) AZ : 2C
     > 서브넷 이름은 ‘KWU-PRD-VPC-TOMCAT-PRI-2C’로 입력
	 > 가용영역은 ‘아시아 태평양(서울) / ap-northeast-2c’로 지정
	 > IPv4 서브넷 CIDR 블록은 ‘10.250.12.0/24’로 입력 후 [서브넷 생성] 클릭
	 
	 
[EC2] - [인스턴스] - [인스턴스 시작] 클릭
 > 이름은 KWU-PRD-VPC-TOMCAT-PRI-2A로 입력
 > AMI는 Ubuntu Server 22.04 LTS(HVM), SSD Volume Type으로 지정
 > 인스턴스 유형은 기본 Default인 t3.micro 사용
 > 키 페어는 이미 생성한 키로 지정 
 
 > [네트워크 설정]에서
   > [VPC]는 이전에 생성한 ‘ KWU-PRD-VPC ’로 지정
   > [서브넷]은 ‘`KWU-PRD-VPC-TOMCAT-PRI-2A`’로 지정
   > [퍼블릭 IP 자동 할당]은 **비활성화**로 변경
   > [방화벽(보안 그룹)]은 기존 보안 그룹 선택으로 변경하고 일반 보안 그룹을 ‘ KWU-PRD-VPC-TOMCAT-PRI-SG-2A ’로 지정
 > [고급 네트워크 구성] 클릭
 [기본 IP]를 ‘10.250.2.240’으로 입력 후 [인스턴스 시작] 클릭



## 3. Was 전용 서버 생성 (`KWU-PRD-VPC-TOMCAT-PRI-2C`)

[EC2] - [인스턴스] - [인스턴스 시작] 클릭
이름은 KWU-PRD-VPC-TOMCAT-PRI-2C로 입력

AMI는 Ubuntu Server 22.04 LTS(HVM), SSD Volume Type으로 지정

인스턴스 유형은 기본 Default인 t3.micro 사용

키 페어는 아까 생성한 키로 지정

[네트워크 설정]에서

[VPC]는 이전에 생성한 ‘`KWU-PRD-VPC`’로 지정

[서브넷]은 ‘`KWU-PRD-VPC-TOMCAT-PRI-2C`’로 지정

[퍼블릭 IP 자동 할당]은 **비활성화**로 변경

[방화벽(보안 그룹)]은 기존 보안 그룹 선택으로 변경하고 일반 보안 그룹을 ‘`KWU-PRD-VPC-TOMCAT-PRI-SG-2C`’로 지정

[고급 네트워크 구성] 클릭
 [기본 IP]를 ‘10.250.12.240’으로 입력 후 [인스턴스 시작] 클릭
